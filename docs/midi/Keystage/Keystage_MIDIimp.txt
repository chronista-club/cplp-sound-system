 1. Transmitted Data
--------------------------------------------------------------------------------


[1-1] Channel Messages
----------------------
                                                           [H]:Hex,  [D]:Decimal
+--------+----------+----------+-----------------------------------------------+
| Status |  Second  |  Third   | Description         (Transmitted by )         |
|  [Hex] | [H]  [D] | [H]  [D] |                                               |
+--------+----------+----------+-----------------------------------------------+
|   8n   | kk  (kk) | XX  (XX) | Note Off            (Keyboard)                |
|   8n   | kk  (kk) | 40  (64) | Note Off            (Button, Encoder)         |
|   9n   | kk  (kk) | VV  (VV) | Note On             (Keyboard,Button,Encoder) |
|   An   | kk  (kk) | vv  (vv) | Polyphonic Key Pressure (Keyboard)            |
|   Dn   | vv  (vv) |          | Channel Pressure        (Keyboard)            |
|   Bn   | cc  (cc) | vv  (vv) | Control Change                             *1 |
|   Cn   | vv  (vv) |          | Program Change      (Pedal 1, Pedal 2, Button)|
|   En   | vv  (vv) | vv  (vv) | Pitch Bend          (Pitch Wheel)             |
+--------+----------+----------+-----------------------------------------------+
 n : MIDI Channel = 0~15
 kk: Note# = 0~127
 VV: Velocity = 1~127
 XX: Velocity = 1~64
 cc: Control Change# = 0~127
 vv: Value = 0~127

 *1: Pedal 1, Pedal 2, Mod Wheel, Knob, Button, Encoder

-----------------------------

+-----------+----------------------+
| Status[H] | Description          |
+-----------+----------------------+
|    F8     | Timing Clock         |
+-----------+----------------------+




[1-3] Universal System Exclusive Message (Non Realtime)
-------------------------------------------------------

 Device Inquiry Reply
+---------+-----------------------------------------------+
| Byte[H] |                Description                    |
+---------+-----------------------------------------------+
|   F0    | Exclusive Status                              |
|   7E    | Non Realtime Message                          |
|   0g    | Global MIDI Channel  ( Device ID )            |
|   06    | General Information                           |
|   02    | Identity Reply                                |
|   42    | KORG ID              ( Manufacturers ID )     |
|   69    | Keystage             ( Family ID   (LSB))     |
|   01    |                      ( Family ID   (MSB))     |
|   mm    |                      ( Member ID   (LSB))     |
|   00    |                      ( Member ID   (MSB))     |
|   xx    |                      ( Minor Ver.  (LSB))     |
|   xx    |                      ( Minor Ver.  (MSB))     |
|   xx    |                      ( Major Ver.  (LSB))     |
|   xx    |                      ( Major Ver.  (MSB))     |
|   F7    | End Of Exclusive                              |
+---------+-----------------------------------------------+
 mm: 01 = Keystage-49, 09 = Keystage-61
 This message is transmitted whenever an Inquiry Message Request is received.

 Structure of Keystage System Exclusive Messages
+------+-------+------------------------------------------------------------+
| Byte | Value | Description                                                |
+------+-------+------------------------------------------------------------+

+------+-------+------------------------------------------------------------+

+------+-------+------------------------------------------------------------+

+------+-------+------------------------------------------------------------+

+------+-------+                                                            |

+------+-------+------------------------------------------------------------+
|   7  |   mm  | 01 = Keystage-49, 09 = Keystage-61                         |
+------+-------+------------------------------------------------------------+
| 8~10 |   ss  | [Function ID] + [Data] length                              |
|      |       | 7bit x 3 (Little Endian)                                   |
|      |       | 0sss ssss  0sss ssss  0sss ssss                            |
+------+-------+------------------------------------------------------------+
|  11  |   nn  | Function ID                                             *2 |
+------+-------+------------------------------------------------------------+

+-------------+----------------------------------------+-----+
| Function ID | Description/Function                   |     |
|    [Hex]    |                                        |     |
+-------------+----------------------------------------+-----+
|     4F      | Scene Change                           | R,C |
|     40      | Current Scene Data Dump                |  R  |
|     51      | Global Data Dump                       |  R  |
|     23      | Data Load Completed (ACK)              |  E  |
|     24      | Data Load Error (NAK)                  |  E  |
|     26      | Receive Data Format Error              |  E  |

|     22      | Write Error                            |  E  |

|     01      | Native Mode Enter/Exit                 |  R  |

|     5F      | Controller Mode Change                 |  R  |

Transmitted when
  R  : Request Message is received.
  C  : Scene is changed.
  P  : Parameter is changed.
  E  : Exclusive Message is received.


[1-5] Search Device Message
---------------------------

 Search Device Reply
+---------+------------------------------------------------+
| Byte[H] |                Description                     |
+---------+------------------------------------------------+
|   F0    | Exclusive Status                               |
|   42    | KORG ID              ( Manufacturers ID )      |
|   50    | Search Device                                  |
|   01    | Reply                                          |
|   0g    | gggg: MIDI Global Channel  ( Device ID )       |
|   dd    | Echo Back ID                                   |
|   69    | Keystage ID          ( Family ID   (LSB))      |
|   01    | Keystage ID          ( Family ID   (MSB))      |
|   mm    |                      ( Member ID   (LSB))      |
|   00    |                      ( Member ID   (MSB))      |
|   xx    |                      ( Minor Ver.  (LSB))      |
|   xx    |                      ( Minor Ver.  (MSB))      |
|   xx    |                      ( Major Ver.  (LSB))      |
|   xx    |                      ( Major Ver.  (MSB))      |
|   F7    | End Of Exclusive                               |
+---------+------------------------------------------------+
 g : MIDI Global Channel = 0 ~ F
 dd: Echo Back ID = copy from SEARCH DEVICE REQUEST message.
 mm: 01 = Keystage-49, 09 = Keystage-61

 This message is transmitted whenever a Search Device Request is received.

--------------------------------------------------------------------------------
 3. MIDI Exclusive Format
--------------------------------------------------------------------------------
                                                         (R:Receive, T:Transmit)

[3-1] Standard Messages
-----------------------

 (1) Scene Change Request                                                         R,-
+----------------+------------------------------------------------------------------+
|     Byte       |                  Description                                     |
+----------------+------------------------------------------------------------------+
| F0,42,4g,      | Exclusive Header  g;Global Channel  [Hex]                        |
| 00,01,69,      | Family ID=000169H                                                |
| mm             | Member ID (Keystage-49 = 01 / Keystage-61 = 09)                  |
| 02,00,00,      | [FunctionID] length + [Data] length = (1+1) = 2 (little endian)  |
| 0001 0100 (14) | Scene Change Request                                             |
| 0000 ssss (ss) | Destination Scene Number (ss=00~15)                              |
| 1111 0111 (F7) | End of Exclusive (EOX)                                           |
+----------------+------------------------------------------------------------------+
 When this message was received, the Keystage loads the scene data to the
 current scene from the internal memory, and transmits a Func=4F(Scene Change) and
 a Func=23(ACK) messages or a Func=24(NAK) message.

 (2) Scene Change                                                                 -,T
+----------------+------------------------------------------------------------------+
|     Byte       |                  Description                                     |
+----------------+------------------------------------------------------------------+
| F0,42,4g,      | Exclusive Header  g;Global Channel  [Hex]                        |
| 00,01,69,      | Family ID=000169H                                                |
| mm             | Member ID (Keystage-49 = 01 / Keystage-61 = 09)                  |
| 02,00,00,      | [FunctionID] length + [Data] length = (1+1) = 2 (little endian)  |
| 0100 1111 (4F) | Scene Change                                                     |
| 0000 ssss (ss) | Scene Number (ss=00~07)                                          |
| 1111 0111 (F7) | End of Exclusive (EOX)                                           |
+----------------+------------------------------------------------------------------+
 When the Keystage completed to load the scene, it transmits this message.


 (3) Current Scene Data Dump Request                                              R,-
+----------------+------------------------------------------------------------------+
|     Byte       |                  Description                                     |
+----------------+------------------------------------------------------------------+
| F0,42,4g,      | Exclusive Header  g;Global Channel  [Hex]                        |
| 00,01,69,      | Family ID=000169H                                                |
| mm             | Member ID (Keystage-49 = 01 / Keystage-61 = 09)                  |
| 01,00,00,      | [FunctionID] length + [Data] length = (1+0) = 1 (little endian)  |
| 0001 0000 (10) | Scene Data Dump Request                                          |
| 1111 0111 (F7) | End of Exclusive (EOX)                                           |
+----------------+------------------------------------------------------------------+
 When this message was received, the Keystage transmits a Func=40(Current Scene Data Dump) or
 a Func=24(NAK) message.

 (4) Current Scene Data Dump                                                      R,T
+----------------+------------------------------------------------------------------+
|     Byte       |                  Description                                     |
+----------------+------------------------------------------------------------------+
| F0,42,4g,      | Exclusive Header  g;Global Channel  [Hex]                        |
| 00,01,69,      | Family ID=000169H                                                |
| mm             | Member ID (Keystage-49 = 01 / Keystage-61 = 09)                  |
| xx,xx,00,      | [FunctionID] length + [Data] length = (1+ss) = xx (little endian)|
| 0100 0000 (40) | Scene Data Dump                                                  |
| 0ddd dddd (dd) | Data                                                  (NOTE 1,2) |
|     :          |  :                                                               |
| 1111 0111 (F7) | End of Exclusive (EOX)                                           |
+----------------+------------------------------------------------------------------+
 When this message was received, the Keystage saves them to the current scene data
 and transmits a Func=23(ACK) or a Func=24(NAK) message.
 When a Func=10(Scene Data Dump Request) message was received, the Keystage
 transmits this message with the current scene data.

 (5) Global Data Dump Request                                                     R,-
+----------------+------------------------------------------------------------------+
|     Byte       |                  Description                                     |
+----------------+------------------------------------------------------------------+
| F0,42,4g,      | Exclusive Header  g;Global Channel  [Hex]                        |
| 00,01,69,      | Family ID=000169H                                                |
| mm             | Member ID (Keystage-49 = 01 / Keystage-61 = 09)                  |
| 01,00,00,      | [FunctionID] length + [Data] length = (1+0) = 1 (little endian)  |
| 0000 1110 (0E) | Global Data Dump Request                                         |
| 1111 0111 (F7) | End of Exclusive (EOX)                                           |
+----------------+------------------------------------------------------------------+
 When this message was received, the Keystage transmits a Func=51(Global Data Dump) or
 a Func=24(NAK) message.

 (6) Global Data Dump                                                             R,T
+----------------+------------------------------------------------------------------+
|     Byte       |                  Description                                     |
+----------------+------------------------------------------------------------------+
| F0,42,4g,      | Exclusive Header  g;Global Channel  [Hex]                        |
| 00,01,69,      | Family ID=000169H                                                |
| mm             | Member ID (Keystage-49 = 01 / Keystage-61 = 09)                  |
| xx,xx,00,      | [FunctionID] length + [Data] length = (1+ss) = xx (little endian)|
| 0101 0001 (51) | Global Data Dump                                                 |
| 0ddd dddd (dd) | Data                                                  (NOTE 1,2) |
|     :          |  :                                                               |
| 1111 0111 (F7) | End of Exclusive (EOX)                                           |
+----------------+------------------------------------------------------------------+
 When this message was received, the Keystage saves them to the internal memory,
 and transmits a Func=23(ACK) or a Func=24(NAK) message.
 When a Func=0E(Global Data Dump Request) message was received, the Keystage
 transmits this message with the global data on the internal memory.

 (7) Scene Data Write Request                                                     R,-
+----------------+------------------------------------------------------------------+
|     Byte       |                  Description                                     |
+----------------+------------------------------------------------------------------+
| F0,42,4g,      | Exclusive Header  g;Global Channel  [Hex]                        |
| 00,01,69,      | Family ID=000169H                                                |
| mm             | Member ID (Keystage-49 = 01 / Keystage-61 = 09)                  |
| 02,00,00,      | [FunctionID] length + [Data] length = (1+1) = 2 (little endian)  |
| 0001 0001 (11) | Scene Data Write Request                                         |
| 0000 ssss (ss) | Destination Scene Number (ss=00~07)                              |
| 1111 0111 (F7) | End of Exclusive (EOX)                                           |
+----------------+------------------------------------------------------------------+
 When this message was received, the Keystage writes the current scene data to the
 internal memory and transmits a Func=21(Write Complete) or a Func=22(Write Error)
 message.

 (8) Mode Request                                                                 R,-
+----------------+------------------------------------------------------------------+
|     Byte       |                  Description                                     |
+----------------+------------------------------------------------------------------+
| F0,42,4g,      | Exclusive Header  g;Global Channel  [Hex]                        |

| 01,00,00,      | [FunctionID] length + [Data] length = (1+0) = 1 (little endian)  |
| 0001 0010 (12) | Mode Request                                                     |
| 1111 0111 (F7) | End of Exclusive (EOX)                                           |
+----------------+------------------------------------------------------------------+
 When this message was received, the Keystage replies a Func=42 (Mode Data) message.

 (9) Mode Data                                                                    -,T
+----------------+------------------------------------------------------------------+
|     Byte       |                  Description                                     |

| 0nnn nnnn (nn) | Mode (nn = 0:Normal Mode / 1:Native Mode)                        |
| 1111 0111 (F7) | End of Exclusive (EOX)                                           |
+----------------+------------------------------------------------------------------+
 This message is transmitted when the Keystage received a Func=12 (Mode Request) message.
