# Looper 操作ガイド

## 基本的な使い方

### シンセ + ルーパーで起動

```bash
# MIDI ポート確認
cplp device midi

# シンセ + ルーパーで起動
cplp play <synth-id> --looper -m <midi-port>
```

### ループ操作（キーボード MIDI）

| キー | 操作 |
|------|------|
| C3 (note 60) | 録音開始 / オーバーダブ開始 |
| D3 (note 62) | 停止 |
| E3 (note 64) | 再生 |
| F3 (note 65) | クリア |

### 基本フロー

1. シンセで演奏しながら **C3** → 録音開始
2. ループしたい長さで **D3** → 停止（ループ長確定）
3. **E3** → ループ再生開始
4. 再生中に **C3** → オーバーダブ（重ね録り）
5. **F3** → バッファクリア、最初からやり直し

## マルチトラック操作

5つのトラックを独立して操作できる。

### トラック切替（CC 70）

CC 70 に値 0-4 を送信してアクティブトラックを変更:

| CC 70 値 | トラック |
|----------|---------|
| 0 | Track 1 |
| 1 | Track 2 |
| 2 | Track 3 |
| 3 | Track 4 |
| 4 | Track 5 |

C3/D3/E3/F3 の操作はアクティブトラックに適用される。

## LPD8 操作

### 起動

```bash
# Keystage + LPD8 同時接続
cplp play <synth-id> --looper -m <keystage-port> --looper-midi <lpd8-port>
```

### パッド操作

| パッド | Note | 操作 |
|--------|------|------|
| Pad 1 | 36 | Track 1 トグル（録音→停止→再生→停止→...） |
| Pad 2 | 37 | Track 2 トグル |
| Pad 3 | 38 | Track 3 トグル |
| Pad 4 | 39 | Track 4 トグル |
| Pad 5 | 40 | Track 5 トグル |
| Pad 6 | 41 | 全トラック停止 |
| Pad 7 | 42 | 全トラッククリア |

### ノブ操作

| ノブ | CC | 操作 |
|------|-----|------|
| K1 | 1 | Track 1 ゲイン |
| K2 | 2 | Track 2 ゲイン |
| K3 | 3 | Track 3 ゲイン |
| K4 | 4 | Track 4 ゲイン |
| K5 | 5 | Track 5 ゲイン |
| K6 | 6 | マスターゲイン（全トラック一括） |

### LPD8 プログラム設定

LPD8 Editor で以下を設定:

- **Program 4** (デフォルト)
- Pad 1-8: Note 36-43, Toggle mode
- Knob 1-8: CC 1-8

### トグル動作の詳細

パッドを押すたびに状態が遷移:

```
Empty → Recording → Stopped → Playing → Stopped → Playing → ...
```

最初の1回は録音開始。2回目で録音停止。3回目以降は再生/停止を交互に切り替え。

## エフェクトとの併用

```bash
# シンセ → エフェクト → ルーパー の順で処理
cplp play <synth-id> --fx <effect-id> --looper -m <midi-port>
```

## 制限事項

- 最大ループ長: 30 秒/トラック
- 最大トラック数: 5
- モノラル/ステレオ対応（cpal のチャンネル設定に従う）
